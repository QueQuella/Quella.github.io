PyTorch · CNN · In Development

Deep Learning — Image Classification

Learning from an NVIDIA deep learning workshop is being applied to the six-label pattern system in Programming Dream.

01 / Question

Human marks, machine labels

How might a machine interpret abstract hand-drawn patterns, and how can a classification result become a creative response in an interactive world?

02 / Background

Learning & method

The experiment builds on CNN and data augmentation concepts learned through an NVIDIA deep learning workshop. The intended local workflow uses Python, PyTorch and torchvision, with six pattern and creature labels.

03 / Dataset

Six categories

Training, validation and test folders are planned for deep_fish, double_wing_bird, fish_bird, long_beak_bird, water_serpent and winged_fish. Drawing samples should be represented in evaluation so performance reflects the participant's actual input style.

04 / Evaluation

Results to document

The record will include dataset counts, augmentation settings, training and validation curves, held-out accuracy and a confusion matrix when an evaluated model exists. An accuracy of 92% or higher is a target, not an achieved result.

05 / Application

Unreal integration

The proposed model output is a label and probability distribution, displayed before confirmation. The confirmed label will select a creature in the Unreal Engine scene. Integration and inference results remain in development.
