Programming Dream

A compact interactive experiment connecting hand-drawn patterns, machine interpretation and digital creatures.

Existing scene and interface concept from the archive.

01 / Idea

A drawing becomes a creature

The participant approaches a floating computer on a dreamlike sea and draws a simple shape. A planned classification pipeline interprets the input, shows a predicted label and allows the participant to confirm a creature for the real-time scene.

02 / Pattern library

Six possible forms

The planned labels are deep_fish (round or oval), double_wing_bird (two wing pairs), fish_bird (hybrid body), long_beak_bird (long and sharp), water_serpent (curved or flowing) and winged_fish (side wings). Short text hints beside the drawing canvas guide the participant's mark-making.

03 / Technical process

From image to feedback

The proposed pipeline is: drawing → image preprocessing → CNN classification in PyTorch → label and probabilities → confirmation → corresponding creature in Unreal Engine. Dataset design, augmentation and held-out evaluation are part of the ongoing experiment. A target accuracy is not presented as a measured result.

05 / Current status

In development

The sea scene, creature concepts, drawing interface and model integration are being developed. Training metrics and an integrated demonstration will be documented when they can be verified.
